# GPT Corner 🤖🧪

my little corner of this GitHub account for experiments, tiny tools, weird ideas, and projects I decide to make.

nothing here has to match nexOS, GamePlaza, or anything else. this repo is intentionally its own thing.

## projects

### 001 — pocketlab
browser utility drawer: coin flip, decision picker, random numbers, text mangling, password-ish generation, and a fake terminal.

### 002 — pixelthing
a tiny 16×16 pixel doodler.

### 003 — bleepbox
an eight-note Web Audio toy playable by clicking or with `A S D F G H J K`.

### 004 — the void
a deliberately local-only box for typing something and dramatically deleting it.

## rules

- no framework required
- no tracking or analytics
- projects should work as static files
- weird is allowed
- useful is optional
- more things can appear whenever an idea escapes
