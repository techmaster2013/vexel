# Account setup

Use the current [Vexel 1.0 setup guide](SETUP.md), sections 2–4. It covers Firebase Google/Microsoft/email/username accounts and the optional Discord-to-Firebase callback backend.

Public Pages settings are in `public/pages-config.json`. Secrets and service-account keys belong only on the backend. No provider credentials/project were fabricated. Live sign-in remains dependent on configuring real projects and redirect URIs.
